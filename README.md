# Сакура · Шафран — Чистополь

Сайт-визитка двух заведений: суши-бар «Сакура» (ул. Ленина, 51) и кафе «Шафран» (ул. Бебеля, 116).

## Что это

Одностраничный сайт-переходник на приложения, соцсети и телефоны заведений. Один `index.html`, без сборки и зависимостей.

## Как обновить

1. Отредактировать `index.html`
2. Закоммитить изменения в ветку `main`
3. GitHub Pages автоматически пересоберёт сайт за ~1 минуту

## Стек

Чистый HTML + CSS + минимальный JS. Шрифты — Google Fonts (Instrument Serif, Inter Tight, Noto Serif JP).
